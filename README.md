# Demonstreerige-oma-OOP

Ülesanne

Tegin PyCharmis lihtsa To-Do List programmi Pythonis.
Programm võimaldab kasutajal:

lisada ülesandeid,
vaadata ülesandeid,
sulgeda programmi.
Kuidas programm töötab

Programmi käivitamisel tuleb menüü:

1 Lisa
2 Kuva
3 Välju
Kui kasutaja vajutab 1, saab lisada ülesande.
Kui kasutaja vajutab 2, kuvatakse kõik ülesanded.
Kui kasutaja vajutab 3, programm sulgub.
Kasutatud oskused

Programmis kasutasin:

klasse,
objekte,
while tsüklit,
if lauseid,
listi,
input funktsiooni.
